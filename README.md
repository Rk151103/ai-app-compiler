# AI App Compiler

A Multi-Stage AI App Compiler built using FastAPI.

## Features

- Intent Extraction
- System Design
- Schema Generation
- Validation
- Repair

## Supported Apps

- Chat Application
- CRM
- Hospital Management System
- E-Commerce

## Run

pip install fastapi uvicorn pydantic

python -m uvicorn main:app --reload

Open:
http://127.0.0.1:8000/docs
